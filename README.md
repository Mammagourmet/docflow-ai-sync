# 🚀 DocFlow AI — Instalador Oficial para Computadores\n\nPlataforma Inteligente de Identificação, Separação e Distribuição Automática de Documentos (PDF, OCR, E-mail e WhatsApp).\n\n---\n\n### 📥 Como Instalar em Qualquer Computador (2 Passos Rápidos)\n\n1. **Clique no link direto para baixar o pacote instalador:**\n   👉 **[Baixar DocFlow-AI-Instalador.zip](https://github.com/Mammagourmet/docflow-ai-sync/releases/download/v1.0.0/DocFlow-AI-Instalador.zip)**\n\n2. **Extraia a pasta e execute:**\n   - Abra a pasta baixada e dê 2 cliques no arquivo **Instalar-DocFlow.bat**.\n   - O instalador configura o ambiente automaticamente, cria o atalho oficial na Área de Trabalho e abre o DocFlow AI no seu navegador em: http://localhost:3001.\n\n---\n\n### 🛡️ Características do Funcionamento Local\n- **100% Independente:** Funciona diretamente no seu computador sem depender de túneis, nuvem ou de outras máquinas ligadas.\n- **Remetente Próprio:** Cada computador utiliza o seu próprio Outlook instalado, Gmail ou WhatsApp.\n- **Segurança Total (LGPD):** Banco de dados SQLite local com criptografia de ponta a ponta (AES-256-GCM).\n
